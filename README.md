# Currency Converter

A simple, responsive currency converter built with HTML, CSS, and JavaScript using live exchange rates.

## Description

This project allows users to convert amounts between different currencies in real time. It features a clean, mobile-friendly interface and fetches the latest exchange rates from a live API so the conversion reflects current market values.

## Features

- Real-time currency conversion
- Responsive layout for desktop and mobile
- Support for multiple currencies
- Simple and intuitive user interface
- Fast client-side updates with JavaScript

## Tech Stack

- HTML
- CSS
- JavaScript

Open the project in your browser to use the converter locally.
